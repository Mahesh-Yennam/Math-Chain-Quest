# Math Chain Quest — Doubling & Multiplication Arcade

An energetic, interactive mental math chain reaction climbing game! Climb glowing plasma energy chains by doubling numbers (`4 + 4 = 8 ➔ 8 + 8 = 16 ➔ 16 + 16 = 32`), solving multiplication ladders (`7 × 2 = 14 ➔ 14 × 2 = 28`), or halving in reverse (`64 ÷ 2 = 32 ➔ 16 ➔ 8`).

Part of the **Gamility** game collection.

---

## 🌟 Features

- **3 Math Modes**:
  - ⚡ **Double It! (×2 / +N)**: Exponential mental doubling (`4 ➔ 8 ➔ 16 ➔ 32 ➔ 64`).
  - ✖️ **Multi-Chain (×3, ×5, ×10)**: Progressive multiplication tables.
  - ➗ **Half It! (÷2)**: Reverse halving chain runs (`64 ➔ 32 ➔ 16 ➔ 8`).
- **3 Difficulty Tiers**:
  - **Starter (Easy)**: 4-link chains starting with single digits (2, 3, 4, 5).
  - **Apprentice (Medium)**: 5-link chains starting with 6–15 (e.g. 7, 8, 12, 14, 15).
  - **Math Master (Hard)**: 6-link chains scaling into hundreds and thousands.
- **Fast 4-Choice Cards**: 4 tactile 3D cards with keyboard shortcut badges `[1]`, `[2]`, `[3]`, `[4]`.
- **Glowing Plasma Ladder**: Visual nodes light up and pulse as you climb closer to the summit.
- **Assistance & Lives**: 3 energy hearts per chain run with gentle learning reveals.
- **Procedural Web Audio Engine**: Ascending synth chord ramps on each step climbed, electronic taps, and summit victory fanfares.
- **Offline & PWA Ready**: 100% client-side zero-dependency code with `localStorage` high score persistence.

## 🕹️ Controls & Shortcuts

| Input | Action |
| :--- | :--- |
| **Tap any of the 4 Cards** | Submits your answer |
| **Keys `1`, `2`, `3`, `4`** | Keyboard shortcuts for the 4 choice cards |
| **Mode Switcher** | Toggles between Double (×2), Multiply, and Half (÷2) |
| **Tier Buttons** | Toggles between Easy, Medium, and Hard |
| **Space / Enter** | Restarts or advances to the next chain on modal |
